# Prixm 자동화 — 화면 설명서

시안을 눌러 보며 화면마다 무엇을 하는지 읽는 도구입니다. `index.html` 이 시작점입니다.

## 여기 있는 것

- `index.html` · `목록.js` — 설명서 도구. 화면 목록과 설명은 **`목록.js` 한 곳**에 있습니다.
- `화면/` — 시안 세 장과 공용 부품(`_공용.css` · `_뼈대.js` · `부품/상단바/_상단바.js`)
- `컴포넌트/` — 제품 컴포넌트 라이브러리에서 **쓰는 것만**(공통 CSS + 아이콘)

## 없는 것

기능명세 엑셀 · 결정 로그 · LAB · 대화 기록 · 제품 덤프는 올리지 않았습니다. 그건 작업용입니다.

## 설명은 확인 전 초안입니다

화면 설명은 **AI 가 시안과 결정 로그를 읽어 정리한 것**이라, 사람이 대조하기 전에는 그대로 믿지 마십시오.
도구에서 설명을 열면 맨 위에 그 표시가 붙습니다. 지금은 설명 패널을 기본으로 감춰 두었습니다.

## `.nojekyll` 을 지우지 마십시오

GitHub Pages 는 기본으로 Jekyll 을 돌리는데, Jekyll 은 **`_` 로 시작하는 파일과 폴더를 건너뜁니다.**
이 프로젝트의 공용 CSS·JS 가 전부 `_` 로 시작해서, 그 파일이 없으면 **스타일이 하나도 안 걸린 맨 HTML** 이 뜹니다.
