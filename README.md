# 화면 설명서

시안을 눌러 보며 화면마다 무엇을 하는지 읽는 정적 사이트입니다. `index.html` 이 시작점(프로젝트 목록)입니다.

```
index.html        프로젝트 목록
자동화/               Prixm 자동화
```

## 프로젝트를 더하려면

작업 폴더의 `공개_굽기.py` 안 `프로젝트들` 에 한 덩이를 적고 다시 구우면 됩니다.
프로젝트 폴더는 **자급자족**합니다 — 컴포넌트 라이브러리를 저마다 담고 있어 서로 안 건드립니다.

## 없는 것

기능명세 엑셀 · 결정 로그 · LAB · 대화 기록 · 제품 덤프는 올리지 않았습니다. 그건 작업용입니다.

## `.nojekyll` 을 지우지 마십시오

GitHub Pages 는 기본으로 Jekyll 을 돌리는데, Jekyll 은 **`_` 로 시작하는 파일과 폴더를 건너뜁니다.**
이 시안들의 공용 CSS·JS 가 전부 `_` 로 시작해서, 그것이 없으면 **스타일이 하나도 안 걸린 맨 HTML** 이 뜹니다.
