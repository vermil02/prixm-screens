변경 기록 — Prixm 시안

이 zip 은 디자인 파일이다 — 실제 제품 코드가 아니라, Prixm 화면이 어떻게 보이고 어떻게 움직여야 하는지를 HTML 로 만든 시안이다.

이 기록은 시안으로 작업하는 사람과 AI 가 무엇이 바뀌었고 어디를 보면 되는지 빨리 찾게 하려고 적는다. 맨 위가 지금 버전이다.

읽는 법

파일 — 화면 하나 = HTML 한 장. 브라우저로 열면 그대로 돈다(서버 없이 더블클릭도 된다).

프로젝트화면파일
자동화① 전체 목록자동화/화면/화면01_전체목록.html
② 자동화 생성 · 설정자동화/화면/화면02_자동화생성.html
③ 자동화 상세자동화/화면/화면03_자동화상세.html
데이터분석① 새 분석데이터분석/데이터분석/정본/화면01_새분석/화면01_새분석.html
② 데이터 · 분석 기법데이터분석/데이터분석/정본/화면02_데이터/화면02_데이터.html
⑤ 결과데이터분석/데이터분석/정본/화면05_결과/화면05_결과.html
  • 공용 부품(상단 바 · 경로 줄 · 스크롤 막대 등)은 …/화면/_공용.css · …/화면/부품/상단바/_상단바.js, 라이브러리 원본은 …/컴포넌트/.
  • 상태는 주소로 연다 — 예: 자동화 ③ ?state=wait|run|fail|off|setup · ?view=run:r3 / 자동화 ② ?tpl=drone&edit=1(설정) / 데이터분석 ⑤ ?view=trend|cross / ② ?tab=method&redo=trend.
  • 각 화면 왼쪽 위 「설명 보기」 = 그 화면의 설명(언제 보이나 · 무엇이 보이나 · 조작 · 규칙). 설명은 AI 가 쓴 초안이라 시안과 다르면 시안이 맞다.
  • 표 · 차트 값, 파일 이름, 날짜, 분석 조건 같은 값은 화면을 보이기 위한 데모값이다.

버전 — v연.월.일-그날 몇 번째. 번호가 빈 것은 화면이 안 바뀐 올림이다. 끝의 7자리는 GitHub 커밋 번호(git checkout <번호> 로 그때 모습을 볼 수 있다).
